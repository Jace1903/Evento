# Evento  
Discover all Bay Area events in one place – from hackathons and tech talks to concerts, cultural festivals, and more.  

Vision  
The Bay Area is buzzing with opportunities: hackathons, tech meetups, cultural events, conferences, and concerts. But finding them is scattered across too many platforms.  

Evento makes discovery effortless by bringing everything together with:  
- 🔍 Smart filtering (tech, networking, cultural, creative)  
- 🤖 Personalized recommendations  
- 📅 Seamless calendar integrations (Google, Outlook, iCal)  
- 👥 Community networking before & after events  

---

Features (MVP)  
- Aggregate events from Eventbrite, Meetup, Luma, Cerebral Valley, and more  
- Category-based search & filtering  
- Personalized event recommendations  
- Calendar sync & reminders  
- Attendee lists + networking features  

---

Tech Stack  
**Frontend:** Next.js (React), TailwindCSS  
**Backend:** Node.js (Express), PostgreSQL, Redis  
**Mobile (future):** React Native  
**Hosting:** Vercel (frontend), Render/AWS (backend), PostgreSQL (Neon/Render)  
**Integrations:** Eventbrite API, Meetup API, Google Calendar API, Auth0/Firebase
